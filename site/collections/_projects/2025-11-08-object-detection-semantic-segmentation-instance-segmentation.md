<p style="margin-left: 20px;">This project demonstrates how to perform object detection, semantic segmentation, and instance segmentation on fisheye images and their undistorted counterparts.</p>
<ul style="margin-left: 20px; padding-left: 40px;">
  <li><b>Image Undistortion:</b> Undistorts fisheye images using calibration data.</li>
  <li><b>Object Detection:</b> Detects objects in images using a pre-trained Faster R-CNN model.</li>
  <li><b>Semantic Segmentation:</b> Segments images using a pre-trained DeepLabV3 model.</li>
  <li><b>Instance Segmentation:</b> Segments instances in images using a pre-trained Mask R-CNN model.</li>
  <li><b>Comparison:</b> Generates comparison images showing the results of the different models on the original and undistorted images.</li>
</ul>
